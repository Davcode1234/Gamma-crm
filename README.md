# 🌟 Gamma CRM

**Gamma CRM** is a lightweight and modern Customer Relationship Management (CRM) application built to simplify client, company, and task management.  
The project uses the **MERN stack** (MongoDB, Express, React, Node.js) and supports real-time collaboration.

---

## 🚀 Features

- Manage clients, companies, and projects  
- Create and assign tasks  
- User authentication with roles and permissions  
- Real-time data updates (Socket.io)  
- Responsive and intuitive UI  

---

## 🛠️ Installation & Setup

### 1. Clone the repository
```bash
git clone https://github.com/Davcode1234/Gamma-crm.git
cd Gamma-crm
```

### 2. Install dependencies

#### Root dependencies
```bash
npm install
```

### 3. Configure environment variables
Create a `.env` file in both the **frontend** and **backend** directories if required.  
For example environment variables or credentials, please contact the author directly.

📩 **Contact:** [davcode1234@gmail.com](mailto:davcode1234@gmail.com)

### 4. Run the project

#### Development mode (concurrently runs client and server)
```bash
npm run dev
```

---

## 🧩 Tech Stack

- **Frontend:** React, Vite, TypeScript, CSS modules  
- **Backend:** Node.js, Express, MongoDB, Mongoose  
- **Other:** Socket.io, JWT Authentication, Formik, Yup
